# DynaSID-POI 模型说明

## 预期用途

DynaSID-POI 是一个研究原型，用于在公开、匿名化的签到数据集上审计语义 ID，并研究动态上下文对下一 POI 检索的影响。

## 模型组成

1. GNPR-SID V2 CRQ-VAE 为每个 POI 构造稳定的三层语义 ID。
2. 静态语义 ID 检索分数提供 POI 身份锚点。
3. 动态残差特征刻画用户重访、近期记忆、POI 转移、多尺度空间重访以及合法的停留/离开行为。
4. 使用软距离惩罚校准地理可达性。

## 证据支持的结论

现有证据支持：DynaSID-POI 在 NYC 上优于相同协议下的静态语义 ID 检索基线，并在冻结权重的 TKY 确认实验中保持改进。现有实验不能证明其优于完整的 GNPR-SID 大语言模型生成器。

## 实验结果

| 城市 / 方法 | Acc@1 | Recall@10 | NDCG@10 | 不可达率@10 | 平均距离@10 |
|---|---:|---:|---:|---:|---:|
| NYC / 静态语义 ID | 0.1746 | 0.4038 | 0.2860 | 0.3800 | 9.02 km |
| NYC / DynaSID-v8 | 0.1925 | 0.5324 | 0.3613 | 0.0031 | 0.92 km |
| TKY / 静态语义 ID | 0.0955 | 0.2556 | 0.1720 | 0.3904 | 9.12 km |
| TKY / DynaSID-v8（冻结参数） | 0.1427 | 0.4616 | 0.2959 | 0.0011 | 0.68 km |

## 已知局限性

动态评分器使用在验证阶段确定的固定权重，而不是端到端学习的权重。目前只评估了两个城市；TKY 存在第一层码本分布集中的现象；可达性仅基于 Haversine 直线距离。大语言模型微调和约束生成部分受限于设备原因未完成。
